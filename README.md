
# Crypto View

Crypto View is a cryptocurrency market tracking and educational web application built with vanilla JavaScript.

Developed as a personal portfolio project demonstrating REST API integration, dynamic data rendering, and interactive frontend development without a JavaScript framework.

## ✨ Features

- Cryptocurrency market data from the CoinGecko API.
- Current prices, market capitalization, and 24-hour price changes.
- Sorting by name, price, price change, and market capitalization.
- Market data pagination.
- Animated cryptocurrency trends.
- Educational content about cryptocurrencies.

## 🛠️ Tech Stack

- JavaScript (ES Modules)
- HTML5
- CSS3 / SCSS
- CoinGecko REST API
- Firebase Hosting configuration

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ArtakN/crypto-view.git
cd crypto-view
```

Serve the project using a local HTTP server.

For example, with VS Code Live Server, open `index.html` using the Live Server extension.

Market data availability depends on the CoinGecko API and its usage limits.
